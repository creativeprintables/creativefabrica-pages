# Creative Fabrica Pages

Static HTML landing pages created to promote digital design resources through Pinterest and direct users to Creative Fabrica.

## Purpose

This repository contains lightweight HTML landing pages for Creative Fabrica design collections and printable resources.

Each page can be used as a destination URL for Pinterest Pins and provides visitors with information about the featured design or collection, together with links to Creative Fabrica.

## Project Structure

```text
creativefabrica-pages/
│
├── halloween-png-printable-illustrations.html
│
├── images/
│   └── ...
│
└── README.md
```

## GitHub Pages

The pages are published using GitHub Pages.

Website:

https://creativeprintables.github.io/creativefabrica-pages/

Individual HTML pages are available through their corresponding file paths.

Example:

https://creativeprintables.github.io/creativefabrica-pages/halloween-png-printable-illustrations.html

## Content

The project may contain landing pages for:

* Halloween Designs
* Christmas Designs

## Page Features

The HTML pages may include:

* SEO-friendly titles and descriptions
* Open Graph metadata
* Responsive layouts
* Product or design previews
* Descriptions and related information
* Links to Creative Fabrica
* Images and other visual assets

## Usage

Pages published through this repository may be used as destination URLs for Pinterest Pins and other promotional channels.

The repository is intended for static HTML content and related assets.

## Maintenance

New landing pages can be added as individual HTML files.

Example:

```text
halloween-witch-bundle.html
christmas-svg-bundle.html
teacher-printables.html
planner-templates.html
```

Each published HTML file receives its own GitHub Pages URL.
